주피터 노트북 실행 방법
======================

1. 작업 폴더에서 PowerShell 열기

파일 탐색기에서 아래 폴더를 엽니다.
C:\Users\asd12\OneDrive\바탕 화면\learnAI

탐색기 위쪽 주소창에 powershell을 입력하고 Enter를 누릅니다.


2. 주피터 설치 (처음 한 번만)

PowerShell에 아래 명령을 입력하고 Enter를 누릅니다.

python -m pip install jupyterlab

(이미 설치했다면 이 단계는 건너뜁니다.)


3. 주피터 실행 

python -m jupyterlab

브라우저가 자동으로 열리면 그 화면을 사용합니다.
주피터를 사용하는 동안 이 PowerShell 창을 닫지 마세요.


4. Password or token 로그인 화면이 나온다면

주피터를 실행한 PowerShell 창은 그대로 두고 새 PowerShell 창을 엽니다.
새 창에서 아래 명령을 실행합니다.

python -m jupyter server list

출력된 내용에서 http://localhost: 로 시작하는 주소를 찾습니다.
?token= 뒤의 실제 토큰까지 포함한 주소 전체를 복사합니다.
주소 뒤에 붙은 공백, :: 표시, 폴더 경로는 복사하지 않습니다.
복사한 주소를 브라우저 주소창에 붙여넣고 Enter를 누릅니다.

주의:
- '긴문자열'이나 '...'은 설명용 예시이지 실제 토큰이 아닙니다.
- 반드시 내 PowerShell에 출력된 실제 주소를 사용하세요.
- 포트 번호가 8888이 아니라면 출력된 번호를 그대로 사용하세요.
- 또는 실제 토큰 값만 화면 위쪽 Password or token 칸에 넣고 Log in을 누릅니다.
- 아래쪽 Setup a Password는 입력하지 않아도 됩니다.
- 토큰은 로그인 정보이므로 다른 사람에게 공유하지 마세요.

실행 중인 서버 주소가 나오지 않으면 3번부터 다시 진행합니다.
